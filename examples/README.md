# Examples

This folder contains example notebooks for SyMANTIC.

- **SyMANTIC_Examples.ipynb** — 6 synthetic case studies (non-dimensional) + 3 dimensional analysis case studies (require external data)
- **SyMANTIC_vs_PySINDy.ipynb** — Lorenz system comparison between SyMANTIC and PySINDy (requires `pysindy` package)
